页面结构

整个应用共 3 个页面 + 2 个 API 接口

页面 /
Dealer 首页 — 选择表单模板 → 填写客户信息 → 点击生成链接
页面 /sign
Client 签字页 — 从 URL 读取数据 → 显示已填表单 → 手写签名 → 提交
页面 /success
提交成功页 — 确认签名完成，提示 PDF 已发送
API /api/generate-link
接收表单数据 + 邮件地址 → 生成 Base64 编码的签字链接
API /api/submit-signature
接收签名图片 + 表单数据 → 合成 PDF → 发送邮件

数据流

1

Dealer 填写表单

选择模板类型 → 按模板填写客户信息 → 输入自己的邮箱

2

生成加密链接

表单数据 + 模板ID + 过期时间(7天) → JSON → Base64 → 拼接到 /sign?d=xxx

3

Client 打开链接签字

从 URL 解码数据 → 预览已填表单 → 在签名板签字 → 提交

4

系统合成 PDF 并发送

用 pdf-lib 把文字+签名叠加到 PDF 模板 → 命名：{模板名}_{客户名}.pdf → Nodemailer 发送到 Dealer 邮箱

URL 数据编码格式

// 编码前的 JSON 数据 { "t": "client-update", // 模板类型 "f": { // 表单字段 "clientName": "张三", "nric": "900101-01-1234", ... }, "e": "yunpeng.chin@cgsi.com", // Dealer 邮箱 "x": 1750345600000 // 过期时间戳 (7天后) } // 编码后: /sign?d=eyJ0IjoiY2xpZW50LXVwZGF0ZSIsImYiOnt...
