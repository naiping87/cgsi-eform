PDF 填充方案

由于 PDF 是平面文件（无表单字段），采用坐标叠加方式

┌──────────────────────────────────┐ │ │ │ 📄 原始 PDF (背景/模板) │ │ │ │ ┌──────────┐ │ │ │ Client │ ← 叠加文字 │ │ │ Name: │ 位置坐标 │ │ │ Tan Ah Kow│ (x,y) │ │ └──────────┘ │ │ │ │ ┌──────────┐ │ │ │ ✍️ Sig │ ← 叠加 │ │ │ [图片] │ 签名 │ │ └──────────┘ 图片 │ │ │ └──────────────────────────────────┘
工作原理：
1. 为每个 PDF 模板写一个坐标配置文件 form-templates.js
2. 配置中定义每个字段的文字位置 (x, y, fontSize, maxWidth)
3. 也定义签名图片的位置和尺寸
4. pdf-lib 读取模板 PDF → 在指定位置画文字/图片 → 输出新 PDF

模板坐标配置示例

// form-templates.js exports.clientInfoUpdate = { // 字段坐标 (x, y, fontSize, page) clientName: { x: 120, y: 680, size: 10, page: 0 }, nric: { x: 120, y: 620, size: 10, page: 0 }, email: { x: 120, y: 350, size: 10, page: 0 }, // ... 更多字段 // 签名位置 signatures: [ { x: 80, y: 80, w: 150, h: 50, page: 1 } ] };
